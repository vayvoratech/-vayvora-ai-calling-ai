# Vayvora Technology - Technical Assessments and Examinations

## Overview
Vayvora Technology conducts rigorous, practical engineering assessments for prospective software engineers, AI developers, cloud architects, and interns. All assessments are designed to evaluate real-world problem-solving, architectural design, and production coding skills.

## Assessment Format and Structure
1. **Practical Coding and Algorithm Assessment:**
   - Covers data structures, algorithmic efficiency, and clean code principles.
   - Typically administered via our secure coding sandbox platform.
   - Standard duration is 60 to 90 minutes.

2. **Domain-Specific Technical Evaluation:**
   - **AI and Machine Learning Tracks:** Practical evaluation on LLM orchestration, RAG architectures, model fine-tuning, and prompt optimization.
   - **Full-Stack Tracks:** Real-time API integration, state management, and responsive component implementation.
   - **Cloud and DevOps Tracks:** Containerization with Docker and Kubernetes, CI/CD pipeline automation, and cloud infrastructure as code.

## Scheduling and Examination Process
- Candidates cannot self-schedule live assessments or interview calls over the phone.
- Eligible applicants whose resumes are shortlisted by our talent acquisition team receive a personalized assessment link and instructions directly via email.
- Once the candidate receives their assessment link, they can complete the 60 to 90 minute hands-on coding or architecture evaluation within their allocated testing window.
- Candidates who complete the assessment will be contacted by our talent acquisition team with their evaluation results.

## Inquiries and Support
- Candidates with questions regarding their application status or assessment results should email talent acquisition at careers at vayvora tech dot com.
- Live meetings or discovery calls are not scheduled for candidate evaluations; all communications and invitations are handled via email.
