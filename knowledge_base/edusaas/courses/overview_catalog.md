# EduSaaS Course Catalog & Curriculum Overview

## About EduSaaS Programs
EduSaaS is the technology education and engineering upskilling division affiliated with Vayvora Technology. We deliver intensive online training programs across all core modern software disciplines, equipped with automated coding assessments, AI voice mock interviews, and production capstone projects.

- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees) per program track
- **Learning Formats**: 
  - **Student Track**: Structured for university schedules with placement preparation, portfolio development, and resume building.
  - **Working Professional Track**: Evening and weekend cohorts focused on scalable system architectures and senior-level upskilling.
- **Official Enrollment Portal**: edusaas.vayvora.com

## Complete Course Portfolio

### 1. Artificial Intelligence & Machine Learning (AI/ML)
- **Focus**: Generative AI, LLMs, RAG pipelines, autonomous AI agents, Deep Learning, and production model serving.
- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees).
- **Key Stack**: Python, PyTorch, Hugging Face, LangChain/LlamaIndex, Redis Vector DB, FastAPI.
- **Capstones**: Real-Time AI Voice Agent, Enterprise RAG Knowledge Assistant, Computer Vision Detection Engine.

### 2. Full-Stack Web & Software Engineering
- **Focus**: Modern front-end and back-end web development, scalable API design, and distributed cloud services.
- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees).
- **Key Stack**: JavaScript/TypeScript, React 19, Next.js 15, Tailwind CSS, Node.js, Express, FastAPI, PostgreSQL, MongoDB, Redis, Docker.
- **Capstones**: High-Concurrency E-Commerce Platform, Collaborative Real-Time Workspace, SaaS Multi-Tenant Analytics Dashboard.

### 3. Data Science & Business Analytics
- **Focus**: Exploratory data analysis, statistical modeling, big data pipelines, machine learning, and executive BI dashboards.
- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees).
- **Key Stack**: Python, NumPy, Pandas, Polars, SQL, Tableau, Power BI, Scikit-Learn, Snowflake/BigQuery.
- **Capstones**: Customer Churn & Lifetime Value Prediction, Financial Fraud Detection, Market Intelligence Dashboard.

### 4. Cloud Computing & DevOps Engineering
- **Focus**: Cloud infrastructure architecture, container orchestration, automated CI/CD pipelines, and Infrastructure as Code (IaC).
- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees).
- **Key Stack**: AWS (EC2, S3, RDS, Lambda, VPC, IAM), Docker, Kubernetes (K8s), Helm, Terraform, Ansible, GitHub Actions, Prometheus, Grafana.
- **Capstones**: Automated Multi-Region Cloud Deployment with Terraform, Zero-Downtime Blue/Green Kubernetes Deployment.

### 5. Cybersecurity & Ethical Hacking
- **Focus**: Threat defense, penetration testing, security operations center (SOC) analysis, network security, and application hardening.
- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees).
- **Key Stack**: Kali Linux, Nmap, Metasploit, Burp Suite, Wireshark, Splunk, Wazuh SIEM, Snort IDS, OWASP Top 10.
- **Capstones**: Enterprise Vulnerability Assessment & Penetration Audit, SOC Incident Response & Threat Hunting Simulation.

### 6. Data Structures, Algorithms (DSA) & System Design
- **Focus**: Problem-solving patterns for top-tier tech interviews, low-level object-oriented design (LLD), and scalable high-level distributed architecture (HLD).
- **Tuition Fee**: ₹5,000 INR (Five Thousand Rupees).
- **Key Stack**: Python/Java/C++, LeetCode 150 patterns, Dynamic Programming, Graph algorithms, Microservices, Caching, Kafka, Redis.
- **Capstones**: Distributed Rate Limiter & Message Queue Implementation, Real-Time Voice Interview Simulations.
